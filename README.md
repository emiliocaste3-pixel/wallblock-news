# wallblock-news
Wallblock News is an AI-powered global financial news platform and mobile app designed for investors and traders. It focuses on real-time markets across Wall Street, Asian bourses, and cryptocurrencies.  Key features include:  Live Market Data: Institutional grade tickers world clocks  commodities (Gold, Silver, Oil), ETFs and an economic calendar.
